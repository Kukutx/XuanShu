# XuanShu 用户体验与运行环境审计

本文件记录具体问题、已实施改进、验收和剩余阻碍。固定 v.0.1.0，未正式发布。

## 业务入口及信息架构

过去全部 22 项功能横向平铺，要求初学者先认识术数工具而不是描述人生问题。
现在默认仅显示九个常用入口，其他 13 项可以通过搜索或展开全部使用。搜索不会打断正在浏览的工作页，也没有移除现有 API。

## 问题驱动咨询

- 初次打开咨询页时问题为空，给出本命、事业、双人、择时、方案五类快捷模板。
- 第二人信息、候选日期、现实条件及完整报告折叠在高级选项中。
- 演示出生日期增加可见风险提示；不能默认为用户真实资料。
- 切换工具时保留尚未提交的咨询草稿，仅在内存中保持；手动保存档案或加密导出才写入本地持久存储。
- 本命盘仍属于传统文化解释框架，不宣称提供科学验证的个人未来预测。

## 可靠性和操作效率

- 修复 Agent 接入视图过期的 21/15/16/14 统计数字，以当前 25 Tools、17 Resources、18 Skills、15 Prompts 为准。
- 专业紫微及择日日历默认当前系统日期，不再显示过去的固定演示日期。
- 401 令牌错误、403 权限错误、服务非 JSON 响应给出直接的排查提示。
- 增加功能检索的原生搜索语义、ARIA 状态、键盘焦点与移动端布局。
- 现有浏览器直接 HTTP 与 FastAPI 交互测试新增搜索和快捷场景验证。
- Agent 接入页面增加 Windows/Linux 对应的 Claude/Codex stdio 配置示例和复制按钮，复制失败提供手动选取提示。

## Python 3.15 正式版升级

- Python.org 3.15.0 正式版已验证 SHA-256 与 Authenticode 后装入 A:/Programming Language/Python315。
- 当前用户默认 python 和 XuanShu .venv 均使用 Python 3.15.0；旧 3.13.7 解释器、用户 PATH 备份、旧 .venv-py313-backup 仍保留。
- uv 已升级为 0.13.0。
- pyswisseph 2.10.3.2 在 Windows Python 3.15 上从源码构建成功；实际安装 iztro-py 0.5.0 并通过 25 个 MCP/REST 工具核验。
- Linux Docker 保留已真实验收的 python:3.12-slim 多阶段镜像，因为检查时 python:3.15-slim 标签未发布。
- 新增 Python 3.15 GitHub CI 独立任务；正式成功与否以最新 Actions 结果为准。

## 仍值得重点投入的产品能力

1. 公网 HTTPS、OAuth 与 ChatGPT/Claude MCP 实际授权和工具调用。
2. 经用户授权的长期档案、跨会话记忆、可导出/删除策略。
3. 真正自主多轮 LLM 咨询协调器及细粒度可复算证据链。
4. 紫微、奇门跨流派的完整独立参考命盘验收。
5. 低熟练度用户测试：完成时间、错误率、读屏与键盘导航。

不应把工具数量或内部回归通过误称为最终专业认证或产品上线。
