# XuanShu 用户体验与运行环境审计

## 2026-10-10：新版 Python 与工作台深度改进

**实际 Python 环境：**
- Python.org 最新正式版：Python 3.15.0（2026-10-09 发布）。
- Windows 已安装 3.15.0；默认 py 解释器、玄枢 .venv 和用户环境变量 PATH 均指向 3.15.0。
- 已启动很久的 DevMate/PowerShell 进程仍缓存旧 PATH，因此其中直接运行 python 可能显示 3.13.7。使用从 Machine+User 环境变量重建的 PATH 后，python --version 实测为 3.15.0。**重新打开终端/IDE**即可继承当前持久化 PATH，不应因旧进程缓存重复安装 Python。
- 3.13.7 保留供旧项目使用，可用 py -3.13 显式运行。pip check 显示玄枢 3.15 环境依赖无冲突。
- Linux CI Python 3.15 虚拟环境具有 .venv/lib64 符号链接。发行脚本现仅对不在排除目录中的符号链接拒绝；增加安全回归，仍严格拒绝可被打包的源码符号链接。

**交互改进（真实 Chrome → Uvicorn TCP 端到端覆盖）：**
- Ctrl+K 全局聚焦功能搜索；中文同义词和常见英文工具词（如 MCP、iztro、择日、事业）均可查找工具。
- 全部 22 个功能支持焦点内方向键、Home/End 切换；按钮保持正确 aria-selected 与 tabIndex 状态。
- 功能直达使用 #tool=白名单工具ID，不会在 URL 中放出生资料、咨询内容或令牌。
- 已经计算命盘后，用户修改出生时间、时区、传统换日方式、太阳时或性别会显示清晰的过期数据提醒并暂时禁用 JSON 导出；恢复到原值后解除提示。
- 咨询报告新增 Markdown 一键复制（实际 Web Clipboard 往返测试通过），同时保留本地下载选项；没有把内容发送给第三方服务。

**仍未完成的产品业务能力：** 真实公网 OAuth/ChatGPT/Claude 远程 MCP 接入、用户许可的跨对话长期记忆、多流派独立参考盘验证、完整可解释自主 LLM Agent。此轮可用性工作没有冒充这些能力已经完成。


本文件记录具体问题、已实施改进、验收和剩余阻碍。固定 v.0.1.0，未正式发布。

## 业务入口及信息架构

过去全部 22 项功能横向平铺，要求初学者先认识术数工具而不是描述人生问题。
现在默认仅显示九个常用入口，其他 13 项可以通过搜索或展开全部使用。搜索不会打断正在浏览的工作页，也没有移除现有 API。

## 问题驱动咨询

- 初次打开咨询页时问题为空，给出本命、事业、双人、择时、方案五类快捷模板。
- 第二人信息、候选日期、现实条件及完整报告折叠在高级选项中。
- 演示出生日期增加可见风险提示；不能默认为用户真实资料。
- 切换工具时保留尚未提交的咨询草稿，仅在内存中保持；手动保存档案或加密导出才写入本地持久存储。
- 本命盘仍属于传统文化解释框架，不宣称提供科学验证的个人未来预测。

## 可靠性和操作效率

- 修复 Agent 接入视图过期的 21/15/16/14 统计数字，以当前 25 Tools、17 Resources、18 Skills、15 Prompts 为准。
- 专业紫微及择日日历默认当前系统日期，不再显示过去的固定演示日期。
- 401 令牌错误、403 权限错误、服务非 JSON 响应给出直接的排查提示。
- 增加功能检索的原生搜索语义、ARIA 状态、键盘焦点与移动端布局。
- 现有浏览器直接 HTTP 与 FastAPI 交互测试新增搜索和快捷场景验证。
- Agent 接入页面增加 Windows/Linux 对应的 Claude/Codex stdio 配置示例和复制按钮，复制失败提供手动选取提示。

- Python.org 3.15.0 正式版已验证 SHA-256 与 Authenticode 后装入 A:/Programming Language/Python315。
- 当前用户默认 python 和 XuanShu .venv 均使用 Python 3.15.0；旧 3.13.7 解释器、用户 PATH 备份、旧 .venv-py313-backup 仍保留。

- 新增 Python 3.15 GitHub CI 独立任务；正式成功与否以最新 Actions 结果为准。

## 仍值得重点投入的产品能力

1. 公网 HTTPS、OAuth 与 ChatGPT/Claude MCP 实际授权和工具调用。
2. 经用户授权的长期档案、跨会话记忆、可导出/删除策略。
