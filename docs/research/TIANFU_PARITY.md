## 1. 对话与智能体

| 天府功能 | 玄枢现状 | 状态 | 补齐方式 |
|---|---|---|---|
| 自然语言对话入口（/chat） | 工作台「AI 对话」与 `POST /api/chat`：用户自备的 LLM（Claude 官方 SDK / OpenAI 兼容）调用 25 个确定性工具 | ✅ | PR 1 已补 |
| 多 Agent 协作（数据整理、校验、流派结论核验、建议整合） | 无 | ❌ | PR 1 先做单模型工具循环 + 结构化核验步骤；多 Sub-Agent 分工列为后续 |
| 可视化、可追溯的推理流程 | 每条回答可展开「推理过程」：工具名、参数、结果摘要与 SHA-256 | ✅ | PR 1 已补 |
| 命盘操作内建，避免模型编造命盘 | 25 个确定性工具 | ✅ | PR 1 强制模型只能引用工具结果 |
| 主动追问（缺资料时追问） | 系统提示要求缺少出生时间、时区或问题范围时先追问 | ✅ | PR 1 已补 |
| 跨对话长期记忆（按档案共享，档案间隔离） | 按本机档案隔离的记忆，模型可提议、用户点击才保存，可删除；服务端不落盘 | ✅ | PR 1 已补（存在浏览器而非云端） |
| 多档案 | 浏览器档案管理 | ✅ | PR 1 让对话绑定当前档案 |
| 多语言输出（中文、English 等 4 种） | 对话回答支持简体、繁體、English、日本語；界面仍为简体中文 | 🟡 | PR 1 已补回答语言；界面 i18n 后续 |
| 海外地区选择 | 支持 IANA 时区和经度手填，无城市选择 | 🟡 | PR 4：内置离线城市表（经纬度 + 时区） |
| 结构化报告（核心结论、详细分析、行动建议、术语解释） | `structured_report` 有可追溯报告，无术语解释 | 🟡 | PR 1 对话可生成报告；术语表后续 |
| 知识库 + 联网资料辅助 | `docs/rules` 规则文档，无检索、无联网 | 🟡 | 规则资源可供模型读取；联网检索不做（不可核验） |
| 不确定性量化（工具、子 Agent、多流派） | 出生时间误差采样、边界地图 | 🟡 | 后续：结论附置信度标签 |

## 补齐顺序

1. **PR 1 AI 对话**：对话页、LLM 工具循环、推理过程展示、档案记忆、四种输出语言、对话本地保存与导出。
2. **PR 2 择日择时**：区间扫描与条件筛选。
3. **PR 3 Life Path**：人生事件锚点与命途回溯。
4. **PR 4 地区与移动端**：离线城市表、Web App Manifest。
5. 需要外部黄金盘的流派扩展（钦天四化、紫微流月流日流时、八字格局用神、更多奇门局法）单独立项，每项先找可引用的规则来源与样本。
