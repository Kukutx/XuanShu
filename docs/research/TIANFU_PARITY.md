## 1. 对话与智能体

| 天府功能 | 玄枢现状 | 状态 | 补齐方式 |
|---|---|---|---|
| 自然语言对话入口（/chat） | 工作台「AI 对话」与 `POST /api/chat`：用户自备的 LLM（Claude 官方 SDK / OpenAI 兼容）调用 33 个确定性工具 | ✅ | PR 1 已补 |
| 多 Agent 协作（数据整理、校验、流派结论核验、建议整合） | 「多流派会诊」模式：八字、紫微、奇门择时三位专家各自只能调用本流派工具（并行），综合者不能调用工具、只依据专家报告作答并列出分歧；独立核验 Agent 只看问题、回答和全部工具原始结果，逐条标注「有工具依据 / 部分依据 / 无依据」 | ✅ | PR 3 补核验 Agent；PR 4 补按流派拆分的 Sub-Agent |
| 可视化、可追溯的推理流程 | 每条回答可展开「推理过程」：工具名、参数、结果摘要与 SHA-256 | ✅ | PR 1 已补 |
| 命盘操作内建，避免模型编造命盘 | 33 个确定性工具 | ✅ | PR 1 强制模型只能引用工具结果 |
| 主动追问（缺资料时追问） | 系统提示要求缺少出生时间、时区或问题范围时先追问 | ✅ | PR 1 已补 |
| 跨对话长期记忆（按档案共享，档案间隔离） | 按本机档案隔离的记忆，模型可提议、用户点击才保存，可删除；服务端不落盘 | ✅ | PR 1 已补（存在浏览器而非云端） |
| 多档案 | 浏览器档案管理 | ✅ | PR 1 让对话绑定当前档案 |
| 多语言输出（中文、English 等 4 种） | 对话回答与界面都支持简体、繁體、English、日本語；繁體全量转换；English/日本語覆盖界面、计算结果的标签、术语与说明文字（具体干支柱值保持汉字） | ✅ | PR 1 补回答语言，PR 2 补界面，PR 5 补计算结果 |
| 海外地区选择 | 内置 65 个国内外城市（时区 + 市中心经纬度），也可手填 | ✅ | 已补 |
| 结构化报告（核心结论、详细分析、行动建议、术语解释） | `structured_report` 有可追溯报告，无术语解释 | 🟡 | PR 1 对话可生成报告；术语表后续 |
| 知识库 + 联网资料辅助 | `docs/rules` 规则文档，无检索、无联网 | 🟡 | 规则资源可供模型读取；联网检索不做（不可核验） |
| 不确定性量化（工具、子 Agent、多流派） | 每条回答附排盘置信度（按出生时间误差 ±1×/±2× 重算年月日时柱与命身宫）和核验 Agent 的把握程度；另有误差采样、边界地图 | ✅ | PR 3 已补 |

## 仍待补齐

1. 需要外部规则来源与黄金盘的流派扩展：钦天四化、北派紫微、八字格局与用神、更多奇门局法。每项先找可引用的规则来源和样本盘再实现。2026-10-11 核查：iztro（MIT）只有一套《全书》四化表；iztro-py 0.5.0 的配置里声明了 `algorithm: zhongzhou`，但源码中没有任何地方使用它，因此不能当作中州派实现引用。
2. 紫微流月、流日、流时：已可通过可选的专业紫微引擎（`ziwei_professional_chart` 传 `target_date`/`target_hour`，iztro-py 的运限输出）取得；原生引擎不重复实现。
