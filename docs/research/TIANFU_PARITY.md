## 1. 对话与智能体

| 天府功能 | 玄枢现状 | 状态 | 补齐方式 |
|---|---|---|---|
| 自然语言对话入口（/chat） | 工作台「AI 对话」与 `POST /api/chat`：用户自备的 LLM（Claude 官方 SDK / OpenAI 兼容）调用 28 个确定性工具 | ✅ | PR 1 已补 |
| 多 Agent 协作（数据整理、校验、流派结论核验、建议整合） | 无 | ❌ | PR 1 先做单模型工具循环 + 结构化核验步骤；多 Sub-Agent 分工列为后续 |
| 可视化、可追溯的推理流程 | 每条回答可展开「推理过程」：工具名、参数、结果摘要与 SHA-256 | ✅ | PR 1 已补 |
| 命盘操作内建，避免模型编造命盘 | 28 个确定性工具 | ✅ | PR 1 强制模型只能引用工具结果 |
| 主动追问（缺资料时追问） | 系统提示要求缺少出生时间、时区或问题范围时先追问 | ✅ | PR 1 已补 |
| 跨对话长期记忆（按档案共享，档案间隔离） | 按本机档案隔离的记忆，模型可提议、用户点击才保存，可删除；服务端不落盘 | ✅ | PR 1 已补（存在浏览器而非云端） |
| 多档案 | 浏览器档案管理 | ✅ | PR 1 让对话绑定当前档案 |
| 多语言输出（中文、English 等 4 种） | 对话回答与界面都支持简体、繁體、English、日本語；繁體全量转换，English/日本語覆盖界面与面板标题，计算术语保持中文 | ✅ | PR 1 补回答语言，PR 2 补界面 |
| 海外地区选择 | 内置 65 个国内外城市（时区 + 市中心经纬度），也可手填 | ✅ | 已补 |
| 结构化报告（核心结论、详细分析、行动建议、术语解释） | `structured_report` 有可追溯报告，无术语解释 | 🟡 | PR 1 对话可生成报告；术语表后续 |
| 知识库 + 联网资料辅助 | `docs/rules` 规则文档，无检索、无联网 | 🟡 | 规则资源可供模型读取；联网检索不做（不可核验） |
| 不确定性量化（工具、子 Agent、多流派） | 出生时间误差采样、边界地图 | 🟡 | 后续：结论附置信度标签 |

## 2. 术数体系

| 天府功能 | 玄枢现状 | 状态 | 补齐方式 |
|---|---|---|---|
| 紫微斗数（钦天四化、北派） | 全书系原生盘 + 可选 iztro-py；无钦天/北派 | 🟡 | 需独立规则来源与黄金盘，单独立项 |
| 紫微流年/流月/流日/流时 | 原生只有年干四化映射；完整运限依赖未验收的可选依赖 | 🟡 | 需参考样本，单独立项 |
| 四化追踪 | 年度四化、连续 1–30 年轨迹 | ✅ | — |
| 子平八字（格局、旺衰、用神、北派用神） | 四柱、十神、藏干、大运；无格局/用神 | 🟡 | 需流派规则与样本，单独立项 |
| 奇门遁甲 | 时家拆补转盘（限定流派） | 🟡 | 其他局法后续 |
| 合盘 | 双人八字四柱对照 + 紫微宫位叠盘（命身宫落点、生年四化入对方盘） | ✅ | PR 2 已补（不打匹配分） |
| 择日择时 | 「择日择时」页与 `date_candidate_scan`：最多 93 天按值日、交节日、本命相冲筛选，可附时家奇门盘 | ✅ | 已补（不打吉凶分） |
| Life Path（人生事件记录、命途回溯、不同选择的轨迹探索） | 档案里记录人生事件，`life_path_review` 逐事件对照大运、流年干支、年度四化与本命地支；不同选择用决策矩阵或 AI 对话比较 | ✅ | 已补 |
