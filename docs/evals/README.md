# 玄枢计算交叉核验评测

这份报告由 `scripts/eval_crosscheck.py` 生成（2026-10-12，年份 1901–2099）。脚本把玄枢的历法和排盘结果与几个独立的开源库逐项对照，原始数据在 [crosscheck.json](crosscheck.json)。任何人装上 [requirements.txt](requirements.txt) 里固定版本的参考库，都能重跑并得到相同结果。

参考库：sxtwl 2.0.7，lunar_python 1.4.8，lunardate 0.3.0，ephem 4.2.1，iztro_py 0.5.0，pyswisseph 2.10.3.2，iztro 2.6.1，@soul-atelier/bazi 0.9.1。玄枢自己用 Swiss Ephemeris（Moshier 星历）计算天象，sxtwl 和 lunar_python 源自许剑伟的寿星天文历，PyEphem 基于 libastro，lunardate 是查表实现，iztro-py 是 iztro 的 Python 移植；iztro-py 没有的辅星、杂曜、十二神和流曜直接对照 iztro 原版（JavaScript，经 Node.js 运行 `scripts/iztro_reference.cjs`）；八字神煞对照 @soul-atelier/bazi（JavaScript，经 Node.js 运行 `scripts/bazi_shensha_reference.mjs`）。

这只核验“算得对不对”，不评价命理解读是否应验；玄枢不对吉凶、预测准确率做任何声明。

编历规则：1929 年起按东经 120°（北京时间）；1912–1928 年按北京地方平时（东经 116°25′）编历（Aslaksen, *The Mathematics of the Chinese Calendar*, 4.2、4.6 节）；1901–1911 年清朝时宪历用的是旧天文法，玄枢按现代天文与北京时间计算，不复现旧法。

## 不一致的原因

- 节气时刻：2025 年以前与寿星天文历最大相差 17.41 秒。之后最大相差 126.25 秒，来自两边对未来 ΔT 的预报不同（Swiss Ephemeris 预报 2026 年 ΔT 为 68.8 秒）。只有出生或事件离交节只差这么几分钟时，月柱才可能因此不同。
- 1933-07-22 至 1933-08-20（30 天）：朔在 1933-07-23 00:03:03+08:00，离午夜 3.0 分钟。只有 lunardate 不同，sxtwl 和 lunar_python 都与玄枢一致。旧算法容易把这样的朔算到午夜另一侧（Aslaksen 记载 1978 年以前香港、台湾历书仍沿用 1908 年的旧历法）。
- 1954-11-25 至 1954-12-24（30 天）：朔在 1954-11-25 20:30:22+08:00，离午夜 209.6 分钟，按天象这一天就是初一。只有 lunardate 不同，sxtwl 和 lunar_python 都与玄枢一致，是这份表的月份长度与天象不符。
- 1978-09-02 至 1978-10-01（30 天）：朔在 1978-09-03 00:08:53+08:00，离午夜 8.9 分钟。只有 lunardate 不同，sxtwl 和 lunar_python 都与玄枢一致。旧算法容易把这样的朔算到午夜另一侧（Aslaksen 记载 1978 年以前香港、台湾历书仍沿用 1908 年的旧历法）。
- 2057-09-28 至 2057-10-27（30 天）：朔在 2057-09-29 00:00:35+08:00，离午夜 0.6 分钟，sxtwl、lunardate 与玄枢差一天。离午夜太近，要看 ΔT 预报，现在无法确定哪边对。
- 2097-08-07 至 2097-09-05（30 天）：朔在 2097-08-08 00:01:27+08:00，离午夜 1.4 分钟，sxtwl、lunar_python、lunardate 与玄枢差一天。离午夜太近，要看 ΔT 预报，现在无法确定哪边对。
- 2095-08-07 正午的月柱（玄枢 癸未，lunar_python 甲申）：这天正午前后交节，两边的 ΔT 预报差一两分钟。
- 2084 年春分：玄枢 2084-03-20 00:00:31，sxtwl 2084-03-19 23:58:51，落在午夜两侧，同样是 ΔT 预报不同。

## 评测带来的修正

- 1914、1916、1920 年各有一个月，玄枢原来一律按北京时间（东经 120°）编历，初一比三家参考都晚一天；这三个月的朔在北京时间午夜后几分钟，按 1912–1928 年实际使用的北京地方平时（东经 116°25′）则在午夜前。已改为这些年份按北京地方平时编历，重跑后三个月全部一致。
- 紫微辅星对照 iztro 时查出两张安星表与所引规则不符：辛年天魁、天钺互换（应为天魁在午、天钺在寅，“辛年午寅”），封诰逆行（应从寅宫起子时顺数到生时）。辛年出生约占一成，封诰只有子时、午时出生原来恰好对。已改正，重跑后全部辅星一致。
