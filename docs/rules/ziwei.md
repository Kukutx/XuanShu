# 紫微斗数计算规则 当前开发阶段

- 朔日农历月日（1929 年起按 UTC+08，1912–1928 年按北京地方平时；依据输入时基对应的本地历日）、出生时辰和传统十二宫命身宫、五行局。
- 星曜覆盖：**14 主星 + 44 颗选定辅/杂曜（其中 26 颗为新增的传统辅助/杂曜）**，仍未实现完整流曜与各派全部星曜；主星既有公开 iztro 命宫/位置基准回归，也不是大规模第三方全流派校验。
- 生年四化按农历年干的《全书》系公开表；宫干飞化列出目标星曜及本命宫所在位置，标注自化；不执行未经验证的吉凶预测。
- 三方四正：本宫、地支间隔 ±4 的两组三合宫与相隔 6 支的对宫。
- `annual_transformations` 只将**指定农历年干四化**映射到本命盘十二宫：不包含完整流年命宫、流星、流月或运限推演。
- 已列四组本命十二神（岁前/将前/长生/博士），其中长生与博士序列需明确性别；另列传统虚岁小限（非周年实际年龄）。
- 大限只列宫位对应的传统起始年龄段；闰月 16 日之后按下一月配置可选择。
- 运限层（`ziwei_horoscope`，`POST /api/ziwei-horoscope`）：给定一个日期（可加时刻），列出当日的大限、小限、流年、流月、流日和流时。每层给出该层命宫所在的宫、按该层命宫重排的十二宫名，以及该层天干的四化落在哪颗本命星上。
  - 大限：虚岁落在哪个本命宫的大限年龄区间；四化取该宫宫干。未到第一个大限（童限）时不列。
  - 小限：本命宫所列小限虚岁；四化取该宫宫干。
  - 流年：农历年地支所在宫为流年命宫；四化取年干。农历年从正月初一起算。
  - 流月：斗君。从流年命宫逆数到生月，再顺数到生时，所到之宫为正月，之后每月顺行一宫；四化取月干（按农历年干五虎遁）。闰月按「闰月后半月按下月」选项分上下半月。
  - 流日：从流月命宫起初一，每日顺行一宫；四化取日干。流时：从流日命宫起子时，每个时辰顺行一宫；四化取时干。
  - 流月、流日、流时要用出生时辰定斗君，时辰不详时不列。目标时刻 23:00–23:59 是否算次日，跟随出生资料的「23:00 换日」选项。
  - 规则与 iztro 一致；交叉核验用 1,000 组随机出生与目标时刻逐层对照 iztro-py（见 `docs/evals/README.md`）。只标出宫位与四化，不安流曜，不预测事件。
- 日界：默认 00:00；选择「23:00 换日」时，23:00–23:59 出生按次日农历日安星，与八字日柱一致。iztro 的晚子时只把日数加一、不进月，所以出生在农历月末最后一天或闰月后半月时两者的命宫可能不同，其余情况一致（见 `docs/evals/README.md`）。
- 支持钟表时间/平太阳时/真太阳时，经度与真实 UTC 时间须明确。不同流派表格可能不同，不擅自宣称唯一标准。

参考：<https://docs.iztro.com/quick-start> 和 <https://www.iztro.com/learn/mutagen>。
