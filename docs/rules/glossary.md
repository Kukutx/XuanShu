# 术语解释

玄枢各工具输出里出现的术语：每条写它是什么、玄枢怎么算，以及详细规则所在的文档。这里只说明含义与算法，不写断语，不判断吉凶；同一术语在不同流派里的算法可能不同，以所列规则文档为准。

`structured_report` 返回报告中出现的术语（`glossary`），MCP 资源 `astro://rules/glossary` 提供全文。本表由 `app/glossary.py` 读取，修改时保持七列表格格式：一行一起讲的几个术语用「、」并列，别名用「／」写在后面；最后两列是英文名和日文名，供界面按语言显示。
