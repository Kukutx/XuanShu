# 出生时刻误差区间 · 离散抽样说明

- 输入 `birth`（出生日期/时区/选用的时制、可选经度）、`uncertainty_minutes`（±5–120）及 `sample_every_minutes`（5–60）。
- 将中心时间先规范化到 UTC，逐点增减分钟，再映射回用户时区；这能避免直接在 DST 缺失/重复墙钟时间上做无效算术。
- 对每个样本独立计算八字四柱、紫微命宫身宫与五行局，并对相同结构去重。
- 报告所列为**实际采样观测到**的不同结构，未采样的分钟可能存在额外变化；不承诺准确识别所有时辰/节令边界。
- 更小的采样间隔可提高观察密度，增加开销。年份范围和时区校验依然适用。
- 命盘结构差异并不具有经科学验证的个人预测效力。不能将区间归类成吉凶分数。
