# 建除十二值日：规则、证据与边界

本功能独立实现中国传统建除十二值日标签，不向第三方网站发送查询。

## 可复算规则

1. 计算北京时间当天 **12:00** 的太阳视黄经；以立春（315°）为寅月开始、每隔 30° 进入下一节令月，得月支。
2. 公历日干支使用本项目已回归的六十甲子日循环，2000-01-01 戊午日作为独立锚点。
3. 当日支等于月建支，标记为「建」；后续地支依次为「除、满、平、定、执、破、危、成、收、开、闭」。计算为 `(日支序号 - 月支序号) mod 12`。
4. 节令月在北京时间当天 00:00 到 24:00 之间切换时，设置 `jie_boundary_on_date=true`。接口的 `officer` 明确是 **北京时间正午标签**，而不是当日全部时刻均适用。
5. 同样的日子里，`jie_on_date` 给出交节的节名、北京时间交节时刻、交节前后的月支和值日（同一日支分别按两个月建计算），正午的值日是其中之一（交节在正午之后为节前的值日，之前为节后的值日）；其余日子为 `null`。网页周历在这一天的格子里写出交节时刻和与正午不同的那个值日（「17:52 → 开」为节后，「成 → 04:02」为节前），突出某个值日时，交节前或交节后才轮到它的那一天也会标出。择日扫描的候选日带同样的字段。

公开传统资料可独立查阅《协纪辨方书》引述的建除规则及现行农民历说明：
- https://zh.wikipedia.org/wiki/建除十二神
- https://www.getauspio.com/zh/blog/day-officers-explained

## 限制

传统节令、月建和建除可作为文化史日历标签；这**不是**完整的择日体系，不输出吉凶、宜忌或适宜签约、行医、投资等行为的保证。部分传统历法存在交节当天的两值处理差异；本实现用正午取样并标明边界日期，不声称穷尽各流派。
