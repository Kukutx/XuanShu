# 适用边界和验证程度

这是传统中国历法与术数符号的**独立计算演示及 Agent 工具**，不具备科学验证的人生预测能力。

1. **农历**：1901–2099 使用现代中国 UTC+08 月相/中气算法，不还原古代历局、所有特殊改历或所有极端天文边界。
2. **八字**：年界采用立春，月界采用十二节令，日界可选子初；传统藏干和十神无强弱权重。
3. **紫微**：14 主星与 44 颗选定辅/杂曜、十二宫、五行局、生年四化、宫干飞化、三方四正；不是全星系/完整流年/流月动态运盘。
4. **四化**：默认十干四化表固定为《全书》系的公开参考，不能和其他流派任意互换。
5. **地理经度**：自动校正采用明确公式，不能消除记录误差、流派差异和 IANA 历史资料局限。
6. **隐私**：默认服务器不保存出生参数。浏览器自愿保存的本地档案为明文 localStorage；加密备份另行使用浏览器 WebCrypto。
7. **用途**：不得作为医疗、财务、法律、重要人生选择或人际关系判断依据。
