# 八字四柱规则 当前开发阶段

- 天文立春（315°）作年干支切换；十二节令（以太阳黄经每 30° 的奇数十五度点）作月界。
- 日柱从 2000-01-01「戊午」锚点累计地方历日；默认 00:00 换日，可选 23:00 子初换日。
- 时柱以双小时地支和日干映射，时辰可用 `clock`、`mean_solar`、`apparent_solar` 三种规则；与年、月柱采用的真实节气 UTC 瞬间不同。
- 支持明干十神、各地支藏干、纳音、无加权五行数量与常见地支关系标签。没有旺衰/喜用神自动断语或精确起运排运。
- 修正真太阳时时，要提供出生地点东经度及 IANA 时区。太阳时模式修正地方日时，不得把钟表时间改动当成天文出生瞬间变动。
- **此项目只供传统文化规则解释，不具备科学的健康/财运/婚姻预测效力。**
