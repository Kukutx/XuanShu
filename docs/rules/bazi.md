# 八字四柱规则 当前开发阶段

- 天文立春（315°）作年干支切换；十二节令（以太阳黄经每 30° 的奇数十五度点）作月界。
- 日柱从 2000-01-01「戊午」锚点累计地方历日；默认 00:00 换日，可选 23:00 子初换日。
- 时柱以双小时地支和日干映射，时辰可用 `clock`、`mean_solar`、`apparent_solar` 三种规则；与年、月柱采用的真实节气 UTC 瞬间不同。
- 支持明干十神、各地支藏干、纳音、无加权五行数量与常见地支关系标签。没有旺衰/喜用神自动断语或精确起运排运。
- 修正真太阳时时，要提供出生地点东经度及 IANA 时区。太阳时模式修正地方日时，不得把钟表时间改动当成天文出生瞬间变动。
- **此项目只供传统文化规则解释，不具备科学的健康/财运/婚姻预测效力。**

## 神煞

`bazi_chart` 每柱输出 `shensha`（神煞名与查法起点），`shensha_rules` 列出盘中出现的神煞的查法与出处；`bazi_dayun` 的大运、流年干支同样带 `shensha`，按原局查。

- 只收能在古籍里查到安法的二十一种。同一神煞各家表格不一（如阴干是否有羊刃、孤辰寡宿是否兼以日支查），这里按下表出处；《三命通会》用文渊阁四库全书本。文昌在《三命通会》与《星学大成》里两表不同、福星表格互有出入，国印、天医在这两部书里查不到八字用的安法，暂不收。
- 太极、红艳原文没写以哪一柱天干查，这里同天乙贵人以日干、年干查；金舆原文举「甲子人禄在寅，辰为金舆」，是以年干查，这里也同天乙贵人以日干、年干查，同章所引《八字金书》以驿马前二辰为金舆的说法不用。太极依原文「皆有始有终之意」，戊己「喜生乎申，得辰戌丑未为正库」，所以戊己见申和辰戌丑未，今通行表戊己只取辰戌丑未。红艳依《三命通会》原文（乙见午、戊见子、壬见巳），与《星学大成》红艳煞歌和今通行表（乙见申、戊见辰、壬见子）不同。学堂、词馆依原文开头的「正位」：以年柱纳音五行（年命）的长生、临官为位，那一柱自己的纳音也须同属这一五行，所以每种五行各只有一个干支；同章接着记下的按干查的说法（子平以日干的甲见亥、乙见午，以及按干的官贵学堂）不用。
- 以日干、年干、年支、日支、月支和年柱纳音为查法起点，查四柱（含起点所在的柱，学堂、词馆不看年柱本身）；时柱可以带神煞，但不作查法起点。时辰不详时页面不列时柱的神煞；若出生当天交节、按 23:00 换日或按太阳时换算，年、月、日柱可能随时辰变化，页面和文字盘都不列神煞。
- 魁罡只看原局日柱，大运流年不标。
- 神煞只是传统标签：不分吉神凶煞配色，不给评分，不据此断吉凶。
- 全部 1901–2099 年每天一盘逐柱对照开源库 @soul-atelier/bazi，规则相同处全部一致（见 `docs/evals/README.md`）；学堂、词馆两边取法不同，不比较。
