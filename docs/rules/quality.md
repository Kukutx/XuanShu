# 排盘边界核验规则 当前开发阶段

`chart_quality_audit` 用于标出可能造成排盘差异的**输入边界和既知历法不确定性**，不是判定命理推断真假的工具，也不是外部专业排盘认证。

- 节令临界：距离前后十二节令距边界不超过指定分钟数时（默认 15 分钟），提示核对出生时刻；八字年/月节令总是用原始天文瞬间计算，不随经度校正改变。
- 时辰临界：使用选定的钟表/平太阳时/真太阳时钟点，与子、丑、寅等时辰分界相比较。
- 子初换日：按项目参数独立核对 23:00 或 00:00 的日界，避免默认混用流派规则。
- 农历月首：提示农历本日为初一或月末时的换月敏感性。
- 跨时区：农历月相按现代中国 UTC+8 确定，排盘日取出生地有效日历日；不同传统排盘口径应显式比较。质量审计额外计算**同一绝对瞬间的北京时间公历日和农历**，当两种农历日不一致时增加 `china_lunar_date_basis_disagreement` 人工复核提示，但不会改变原命盘。超出支持的 1901–2099 UTC+8 对照日只提示无法计算，不伪造结果。
- 远期新月不确定性：香港天文台公开声明 2057-09-28、2089-09-04、2097-08-07 附近新月日期可能偏差一天。项目 Moshier 实现与其表在 2057-09-28、2097-08-07 不同；**标记后续该农历月受影响区间，不强制篡改计算结果**。这不是全面 1901–2099 年逐日外部校验。

权威参考：[香港天文台公历农历对照表（含远期边界说明）](https://www.hko.gov.hk/en/gts/time/conversion.htm)。

输出状态 `review_needed` 仅表示发现边界提示。即使为 `false`，也不代表专业流派正确、外部历书认证或科学预测有效。
