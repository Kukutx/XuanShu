# 时家奇门拆补转盘：明确流派计算说明

**实现范围**：`POST /api/qimen` / MCP `qimen_hour_chart` / CLI `qimen` / Web 九宫视图。

- 入参 `moment` 按本项目 `BirthInput` 时区和时间基准校验；节气使用真实 UTC 事件时刻，不以整天判断。
- 以 **日干每五天为一个符头** 推出符头地支。子午卯酉为上元、寅申巳亥为中元、辰戌丑未为下元。以当前 24 节气和三元局数表确定阴阳遁与九局。
- 以 `戊己庚辛壬癸丁丙乙` 的固定传统顺序，从局数所在宫顺/逆排地盘，固定六十甲子的旬首六仪（甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸）。
- 八宫顺时针环 `1,8,3,4,9,2,7,6`；以旬首干地盘宫为值符星原宫、当前时干落宫为值符到宫。天盘八星及天盘干同步沿环旋转；天禽留中宫。值使门按时辰在宫数 1..9 顺/逆飞，八门沿环排列。八神按阴逆、阳顺沿环排列。
- 中宫（第 5 宫）对值符、值使、时干采用**寄坤二宫**。中心天盘干、星保留作为结构记录；不同流派对此有差异。
- 空亡按当前**时柱旬首**的最后两个未出现地支标记。

传统局数表及基础宫位序列可与许可为 MIT 的 `https://github.com/AbelardZ/QiMen` 中公开的常量表交叉核对；本模块独立编写，不调用该项目 API。另外与 MIT 项目 [`qfdk/qimen`](https://github.com/qfdk/qimen/blob/main/test/paipan.test.js) 中五组 2026 年公开盘校对了 **阴阳遁/局数、值符星/落宫、值使门/落宫六项字段**，一致。**不能据此声称全部九宫天盘、暗干和其他流派逐宫验证完成。**

已识别一项可解释的外部差异：2026-06-05 16:52（北京时间）尚未交芒种（交节约 23:48），本项目按*实际天文时刻*记为小满，而一些公开程序按*节气所在公历日*提前记为芒种。此处不强制改成外部项目的旧版日期判断。

本版本**不支持**置闰、飞盘、茅山、鸣法、日家/月家/年家、刻家，以及复杂流派断法。它不声称科学预测功效；不能用于现实择日择时保证。
