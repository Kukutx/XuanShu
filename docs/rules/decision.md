# 透明决策矩阵：与术数严格隔离

此功能用于用户指定的多个现实方案的**主观**比较，绝不使用八字、紫微或择日结果作为评分依据。

每个评价指标含名称和大于零的权重；每个方案在全部指标下提供 0–5 的用户输入评分。

1. 归一化权重：`w_i' = w_i / Σw_i`。
2. 加权得分：`score(option) = Σ w_i' × rating(option, i)`；结果范围是 0–5。
3. 逐项剔除一个指标后重新归一化并重算，看首位方案集合是否改变；这只是一种敏感性检查。
4. 分数相同时标记共同首位，输出稳定展示顺序；不虚构「获胜概率」。

它不能验证评分是否真实、是否遗漏关键信息，更不能代替事实核对与专业建议。尤其不应用于单纯通过分数处理医学、法律或重大投资选择。
