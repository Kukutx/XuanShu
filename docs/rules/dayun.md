# 大运十年干支序列（独立计算约定）

算法明确固定以下口径，**不作现实预测**：

1. 年柱以**立春**为界；年干阳（甲丙戊庚壬）配男性或年干阴配女性向前，其他向后。允许显式 `direction_override`，若性别未指定且未选择方向，则拒绝推断。
2. 自出生时刻找**十二节**（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒）中下一节（顺行）或上一节（逆行）。节气是精确时刻，不是节气日期的午夜，也不能把中气（春分等）算进去。
3. **出生时刻恰好等于节令求得时刻时按零时差处理**，不错误地跳到下一节；出生到节令的实际 UTC 时间差，按「三日一岁，一日四个月」比例折为**名义传统起运岁数**。
4. 从本命**月柱**后一位（顺行）或前一位（逆行）起，沿六十甲子每十年更替一次。
5. 为方便时间轴显示，将名义年龄按每年 365.2425 个**均值日**投影为公历时间，误差不可当作精确交运日；不同流派使用不同的年龄进位、日时换算与交运口径。
6. 每步大运另给 `natal_interactions`：该运干支的十神、纳音，日主在该支的星运（十二长生）与该运天干的自坐，该支是否落在日柱或年柱的旬空，与原局每一柱的天干五合、相冲和地支同支、六合、六冲、六害、相刑（相刑不分先后，寅巳申、丑戌未、子卯与辰午酉亥自刑），以及该支与原局地支凑齐的三合局、三会方。请求 `include_years: true` 时，每步大运再列出流年并同样读出：按常见排法从交运所在的公历年列到下一步交运的前一年，交运当年整年记在新大运下（交运日之前的几个月实际仍属上一步大运），相邻两步不重不漏；年柱以立春换年。请求 `month_year`（1901–2099）时另给 `flow_months`：该立春年的十二个流月，立春起寅月，每月从本月的节交接时刻到下一节（第十二个月到次年立春），月干按五虎遁从年干起（甲己之年丙作首，乙庚戊、丙辛庚、丁壬壬、戊癸甲），同样读出十神、星运、空亡、干支关系与神煞，不列藏干。再给 `day_month`（1–12，1 是寅月）时，该月另列 `days`：从交节那天到下一节前一天的每个公历日及其日柱（午夜换日，交节当天整天列在新月下，交节时刻之前其实仍属上个月，`jie_day` 标出这一天；时区整天跳过的日期不列出，例如萨摩亚 2011-12-30），读法同上。`hour_unknown: true` 时不与时柱比较。这些只是关系标签，不判断合化成败，也不据此断吉凶。
7. 多人关系（`group_relations`）或双人对照（`pair_comparison`）传入 `year` 时，用同一套排法列出每位成员当年所在的大运：按上面第 6 条的交运年列法找到包含该年的那一步，十神以本人日主看大运天干；性别未填的成员不排大运；该年早于第一步交运年时标「未起运」并给出起运年。出生时辰不详时，起运年龄会随当天的出生时刻移动最多约三分之一岁，所以按出生当天最早与最晚的时刻各排一次：两者同一步大运而交运年不同时给出两个交运年，落在不同的两步时并列两种可能，不再参与成员之间的比较；出生当天交节而月柱可能有两种时不排大运。流年对每个人相同，按立春年柱读出它与各人原局的十神、星运、空亡、干支合冲刑害、补成的三合三会与神煞（原局有当天会变的柱时不读）。成员之间只比较各自的大运：天干五合与地支同支、六合、六冲、六害、相刑。同时给出 `luck_timeline`：每位成员十二步大运各自列出的公历年（从交运那年到下一步交运的前一年），供时间轴使用；时辰不详时同一步大运在出生当天早晚的交运年可能差一年，`start_years`、`end_years` 列出两个年份。
