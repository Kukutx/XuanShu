# 出生时间区间的计算边界地图

相比 `birth_time_window` 每 N 分钟采样，`birth_boundary_map` 针对**已实现的**八字/部分紫微规则，列出分钟检测后以秒级求根的模型切换点：
- 传统时辰（有效读数 23:00、01:00、03:00 等）；传统日界（午夜与可选的 23:00）；
- 实际 UTC 与出生时区历史/夏令时 offset 切换；
- 十二节令的天文计算时刻（影响八字月柱，立春同时改变年柱）。

将时间区间拆成 UTC 半开区间（每段同时给出出生时区的本地起止时刻 `start_local_inclusive` / `end_local_exclusive`，跨夏令时切换时两侧偏移各自正确），每段中点调用原排盘引擎构造代表性结果；边界精确至约一秒，但**不表示**出生资料本身可精确到一秒，也不保证其它紫微流派或尚未实现的规则不产生新边界。

支持范围：出生时刻离 1901 年初或 2099 年末不到误差范围时，区间截到支持范围的边缘：钟表时间或所选的太阳时读数先离开 1901–2099 年的那一刻，起点含、终点不含（钟表时间下就是出生时区的 1901-01-01 00:00 起、2100-01-01 00:00 止），`clipped_to_supported_range` 列出截掉的一侧，`birth_utc` 给出出生瞬间，`limitations` 加一句说明；截掉的部分没有检查。

隐私：无服务器持久化，不自动保存出生资料。特别提醒：有些年代的 IANA 时区政策会导致同一个钟表时刻不存在或对应两个 UTC 瞬间，输入歧义时须提供 ISO UTC offset。

网页把区间画成一条时间轴：每段一条色带、每个切换点一个编号刻度、记录的出生时刻一枚金色标记；切换点逐个写出前后两段哪些字段变了（四柱、命宫、身宫、五行局、农历日），各段卡片标出与出生所在段不同的柱和紫微字段。
