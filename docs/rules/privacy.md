# 隐私和数据处理

- 核心计算、MCP、REST 默认**不在服务器数据库保存出生资料**。
- Web 控制台中「保存到本机」需要主动点击。内容只存到当前浏览器的 `localStorage`，不会同步服务器，也不包含 API 访问令牌。使用公共电脑请避免保存个人出生信息。
- 可以在页面中逐条删除本地资料；也可以自行清理浏览器的网站数据。
- API / MCP 运行时仍需要向当前部署的服务器传送输入。公网服务应使用 HTTPS、鉴权、速率限制和日志脱敏。
- 导出 JSON 是用户主动从浏览器下载，会包含出生日期时间，需自行管理文件隐私。
- 另支持由浏览器本地 WebCrypto 派生密钥的 AES-256-GCM 加密备份（PBKDF2-SHA256，250000 次），仅对**备份文件**加密，口令不上传；原先选择保存在 localStorage 的档案依旧是明文。
- 综合报告 Markdown 下载同样由用户主动触发，且服务器不持久化报告。
- 不包含第三方追踪服务或后台账户系统。
