## 时家奇门独立交叉核验

以 MIT 公共项目 [qfdk/qimen 的公开测试](https://github.com/qfdk/qimen/blob/main/test/paipan.test.js) 为参照，在 2026 年 `03-21`、`06-09`、`07-15`、`09-23`、`12-08` 正午共 **5 个输入**，比较阴阳遁、局数、值符星、值符落宫、值使门、值使落宫共 **6 个共同字段**，一致；另与该项目五盘的九宫暗干共 45 格分别核对，一致。该单一开源实现并非第三方权威专业认证。

**公开样本存在时令处理差异**：2026-06-05 16:52 的“芒种”标签来自把节气按**整个公历日**归类的某些排盘实现；天文学的芒种到来在同日约 23:48 北京时间。本项目坚持节气**实际发生瞬间**，在 16:52 仍为小满。不同规则不能静默混用。

验收完整奇门前，还必须跨不同实现完整核验九宫地干、天干、门星神、暗干、伏吟反吟、空亡/驿马、宫寄处理，并在各种节气、闰月、DST、临界时刻给出黄金盘集。当前不把文化标签转成现实吉凶概率。

## 正式远程 Plugin 验收条件

必须有可长期访问的 HTTPS `/mcp`，公开 `/.well-known/oauth-protected-resource/mcp`，受信任外部 OAuth 发行者和正确的受众/权限配置；在 ChatGPT 与 Claude **分别**完成授权、工具列表获取、真实排盘调用、拒绝越权和撤销权限测试。没有这些真实验收，任何 ZIP 都不是“已安装好的云端 Plugin”。

## 本轮修复后仍待的验证（2026-10-10，版本不变）

- **Docker：** 默认匿名本地模式无法把容器网桥源地址当成回环，本轮改成默认 Compose `127.0.0.1` 发布 + 生成随机密钥 + 显式 Bearer/Host/Origin 验证；未在当前 Linux 环境启动 Docker（缺 CLI），只能通过容器 IP 模拟、构建配置和 CI 运行步骤确认代码路径。
- **MCP：** 已防御参数中非字符串协议版本导致的非预期 TypeError；没有外部 Claude 或 ChatGPT 原生远程插件接入实验。
- **浏览器：** Chromium 对 `127.0.0.1` 的直接页面导航受到本环境管理员访问策略拒绝（`ERR_BLOCKED_BY_ADMINISTRATOR`）；真实页面仍仅以 Chromium + FastAPI in-process 桥接验证，而 Uvicorn Socket 另外独立联调。这两项不能冒充完整浏览器到网络的 E2E。
