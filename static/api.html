接口文档

工作台的每个页面都调用这里的接口；脚本、表格软件和 Agent 也能直接用。每个接口都附一个能直接运行的示例，可以改了再发送。

  • 本机计算出生资料只用于这一次请求，服务端不保存。
  • 严格字段POST 收 JSON；多写或拼错的字段返回 422，不会被静默忽略。
  • 时间写法当地钟表时间加 IANA 时区；夏令时回拨的重复时刻在时间后写偏移，如 1988-09-11T01:30+09:00。
  • Agent 接入同一套计算也在 MCP 端点 POST /mcp（JSON-RPC 2.0）。机器可读的说明：openapi.json ↗
连接设置 本机运行可跳过

只在这个页面发请求时使用，不会保存；复制的 curl 用环境变量 MCP_BEARER_TOKEN 代替。
